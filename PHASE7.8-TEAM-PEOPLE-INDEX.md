# Phase 7.8 — Team People Index

## Purpose
Refine the remaining multidisciplinary-team surface so it reads as an editorial people index rather than a boxed staff directory, while keeping the Phase 7.7 progressive profile sheet.

## Changes
- Keeps the two-column roster, but replaces boxed cells with quieter editorial rows and horizontal rules.
- Increases name prominence and reduces the visual weight of initials placeholders.
- Keeps a restrained `Profile / Perfil` cue plus a directional arrow for clear clickability.
- Expands the right-side profile sheet slightly for a more comfortable reading measure.
- Adds a governed `Professional context / Contexto profesional` section with role, specialty/field and service/affiliation.
- Keeps biographies, research relationships and scholarly links conditional on public data.
- Uses specialty/field as the concise identity descriptor when available, avoiding duplicated role + specialty language in the sheet header.

## Data rule
No biography, expertise claim or output is invented. The richer profile comes from structuring existing public fields more effectively.
